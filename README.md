# Brausewetter 1895 — Das Bauformenbuch, Bd. 1

Цифровое научное издание, корпус текстов и **Интерактивный пропорциональный калькулятор фасада** по книге:

- **Автор:** Brausewetter
- **Издание:** *Das Bauformenbuch*, Bd. 1, 1895
- **Источник факсимиле:** Deutsches Museum ([BV014442283](https://gateway-bayern.de/BV014442283))

---

## Разделы приложения

1. **Читальный зал** — постраничная дипломатическая немецкая транскрипция, русский перевод, синхронизированный вьювер факсимиле и двусторонняя подсветка архитектурной терминологии.
2. **Калькулятор** — параметрический калькулятор пропорций фасада по страницам **S. 1–23**, включающий три подстраницы:
   - *Фасад и калькуляторы* (10 модулей с поэтажной геометрической моделью `Levels`, переключателем `Эксперт (P3)`, метками происхождения `sourceStatus` + динамический SVG-фасад на 1–5 этажей / 2–10 осей с положением входа и 6 геометрических номограмм и разрезов).
   - *Правила и нормы* (41 запись правил из единого JSON-реестра `src/calc/rulesData.json` со ссылками на S. 1–23, статусами происхождения и фильтром P3).
   - *Тесты (11 кейсов)* (интерактивная проверка контрольных примеров из книги).
3. **Терминология** — двуязычный глоссарий с переходом к месту употребления в тексте.
4. **Корпус JSON / Опись издания** — просмотр и экспорт полного корпуса.

## Архитектура калькулятора и список правил (S. 1–23)

Чистая математическая логика вынесена в `src/calc/rules.ts`, а метаданные правил, типологий и отношений — в `src/calc/rulesData.json` (**41 запись правил** с метками происхождения `explicit-verified | explicit-unverified | heuristic | editorial | gap` и приоритетами `P0–P3`). Все промежуточные расчёты ведутся без округления по поэтажной модели (`BuildingLevelsInput` → `DerivedGeometry`); отображение форматируется до 3 знаков после запятой (`м`).

1. **`axenweite_zimmerhoehe` (S. 5–6):** `A = H_max × (n/m)`; жилой дом `2:3 … 8:9`, дворец `5:6 … 1:1`, богатая колонно-пилястровая архитектура `→ 1:2`.
2. **`pfeiler_ohne_umrahmung` (S. 5):** `p = A − w`, проверка `p ≥ w` (`A ≥ 2w`); для `rich_columnar` правило отменено (`ok`).
3. **`pfeiler_mit_umrahmung` (S. 5):** `w_v = w + 2u`, `p_c = A − (w + 2u)`, проверка `p_c ≥ w_v`.
4. **`eckpfeiler_abstand` (S. 4–5):** `D = k_D × A` (`k_D ∈ [2/3, 5/6]`, по умолчанию `4/5`); `p_corner = D − w/2 − u`. Проверки зависят от типа здания (отдельно стоящий: `p_corner > w`; монументальный: `p_corner > p_intermediate`; городской: допускается `p_intermediate ≥ p_corner`; ризалит на ширину комнаты: `D = ширина_ризалита / 2`).
5. **`fenster_hoehen_grenzen` (S. 6):** `1.5w ≤ h ≤ 2w`.
6. **`fenster_goldener_schnitt` (S. 6–7):** `h = φ·w` (`φ = (1 + √5)/2 ≈ 1.618034`) и практические приближения `3:5, 5:8, 8:13, 13:21, 21:34, 34:55, 55:89, 89:144` (а также `5:9, 4:7`).
7. **`fenster_halbe_diagonale` (S. 7):** `d = √(w² + h²)`, правило `w ≤ d/2`.
8. **`fenster_verdachung_rfk` (S. 7–8):** деление `R:F:K` (`1:1:1, 6:7:8, 4:5:6, 3:4:4, 2:3:3, 3:5:4`).
9. **`ausladung_45_und_konsolen` (S. 8):** вынос по `45°` (`v_proj = K`), с консолями `v_console = (5/6)·K`, равенство отступов `a_front = a_side`.
10. **`pilaster_vorsprung` (S. 11–12):** `v_max = W_p/4`; лёгкий диапазон `W_p/6 … W_p/5`; гладкая лопатка (`Mauerpfeiler`) без базы и капители.
11. **`kranz_gliederung` (S. 10–11):** `h_u : h_l = 1:1` (допустимо `1:2 … 2:1`).
12. **`sockel_gesammthoehe` (S. 16):** оптимально `h_socle = H_total / 6`, типично `1/10 … 1/7`; при `< 1/10` — нарушение.
13. **`hauptgesims_unterordnung` (S. 16):** `h_main < h_socle`; диапазон `[H_total/12, H_total/8]` (≤ 2 эт.) и `[H_total/15, H_total/12]` (> 2 эт.).
14. **`gurtgesims_abmessung` (S. 16):** поясной карниз `h_gurt ∈ [H_floor/12, H_floor/6]` и строго меньше главного карниза и цоколя.
15. **`sockel_dreiteilig` (S. 10):** трёхчастное деление цоколя (`Fuß`, `Rumpf`, `Deckgesims`) и преобладание плиты.
16. **`sockel_abnahme_nach_oben` (S. 10):** убывание высоты руста и выноса профилировки от цоколя к первому этажу.
17. **`sockel_abkroepfung` (S. 10, 12):** предпочтителен сплошной прогон без раскреповок; раскреповки допустимы при подвальных окнах или лопатках.
18. **`sockel_quader_schichten` (S. 17):** высота рядов квадровой кладки `0.30–0.40 м`, предпочтительно нечётное число рядов `n`.
19. **`erdgeschoss_als_sockel` (S. 16, 22):** включение всего 1-го этажа в цоколь от земли (`groundToFloor1 + floor1.floorToFloor ≥ h_socle_required`).
20. **`varianty_etazhnosti_i_pryamougolnik` (S. 5–6, 14–16, 21–22):** 5 пресетов этажности с объединённой проверкой `allowedAxisRatio`, лежачего/стоячего прямоугольника (`±2 % / ±5 %`) и согласованностью осей с положением входа (`entrancePosition`).
21. **`gurtgesims_lenta_pravila` (S. 10–11, 16–17, 22):** межэтажные карнизы (ленты): унифицированный расчёт `checkBeltHeight`, 4 класса состава, разбивка венца `1:2…2:1`, согласование с колоннадой, рустовка на `Fußprofil`, 3 схемы 3-этажного дома.
22. **Новые правила S. 12–23 (`N1–N29`, 18 записей в `rulesData.json`):** наличник `u ∈ [w/6, w/5]` (`N1`), подоконная плита `w/8..w/7` (`N2`), сплошной подоконный пояс `> u` (`N3`), `7–8` рядов руста в окне (`N4`), нечётная угловая рустовка (`N5`), уступ `M ≤ N` (`N6`), группировка чётных/длинных фасадов (`N7`), пропорции крыльев/ризалитов и 5-/7-частные схемы `1.5:3:5:3:1.5` (`N8–N17`, `N23`, `N25`), многоярусные пилястры (`N18–N19`), 5-этажные схемы `standard` / `rich_1_2_unified` (`N27–N28`), редкий подоконник под 2-м эт. (`N29`) и экспертные проверки **P3** (`N20–N22`, `N24`, `N26`).

### Принятые допущения и пробелы источника (1895)

В интерфейсе явно помечены метками `sourceStatus` (`Из книги`, `UX-эвристика`, `Пробел`):
- **Допуски проверки:** `tolerance = 3 %` для шага осей и `diagTolerance = 7 %` + `KNOWN_GOOD_RATIOS` (`3:5`, `5:8`…) для правила половины диагонали окна (`S. 7`).
- **Пороги UX поверх качественных указаний:** доля плиты карниза (`≥ 75 %` / `≤ 50 %`), доли 3-частного цоколя (`0.25 / 0.55 / 0.20`) и преобладание плиты (`1.2×`), пороги квадрата фасада (`±2 % / ±5 %`), вырождение `onlySillUnderSecond` (`> 0.55·H_total`) и `±15 %` для 7-частного фасада / смежных пилястр.
- **6 пробелов по этажности (`VARIANT_TEXT_GAPS`)** и **4 открытых пробела по межэтажным лентам (`BELT_TEXT_GAPS`)** — вынос `Ausladung`, `Fuß:Rumpf:Deckglied` ленты, пороги скромного 1-го этажа и колоннады. (База высоты этажа пол-до-пола и высота сплошной подоконной плиты `> u` закрыты первоисточником S. 5 и S. 17.)

```bash
npm install

npm test          # запуск 50 автоматических unit-тестов (src/calc/rules.test.ts)
npm run lint      # проверка типов TypeScript (tsc --noEmit)
npm run build     # сборка для публикации в dist/
```
