# Brausewetter 1895 — Das Bauformenbuch, Bd. 1

Цифровое научное издание, корпус текстов и **Интерактивный пропорциональный калькулятор фасада** по книге:

- **Автор:** Brausewetter
- **Издание:** *Das Bauformenbuch*, Bd. 1, 1895
- **Источник факсимиле:** Deutsches Museum ([BV014442283](https://gateway-bayern.de/BV014442283))

---

## Разделы приложения

1. **Читальный зал** — постраничная дипломатическая немецкая транскрипция, русский перевод, синхронизированный вьювер факсимиле и двусторонняя подсветка архитектурной терминологии.
2. **Калькулятор** — параметрический калькулятор пропорций фасада по страницам **S. 1–12, 14–17, 21–23**, включающий три подстраницы:
   - *Фасад и калькуляторы* (10 модулей: оси и простенки, этажность, окно, угол `D`, обрамление `R:F:K`, пилястр, карниз, цоколь, **лента (пояс)**, сводка + динамический SVG-фасад на 1–5 этажей / 2–10 осей и 6 геометрических номограмм и разрезов).
   - *Правила и нормы* (карточки правил из единого JSON-реестра `src/calc/rulesData.json` со ссылками на страницы источника).
   - *Тесты (11 кейсов)* (интерактивная проверка контрольных примеров из книги).
3. **Терминология** — двуязычный глоссарий с переходом к месту употребления в тексте.
4. **Корпус JSON / Опись издания** — просмотр и экспорт полного корпуса.

## Архитектура калькулятора и список правил (S. 1–12, 16–17, 22)

Чистая математическая логика вынесена в `src/calc/rules.ts`, а метаданные правил, типологий и отношений — в `src/calc/rulesData.json`. Все промежуточные расчёты ведутся без округления; отображение форматируется до 3 знаков после запятой (`м`).

1. **`axenweite_zimmerhoehe` (S. 5–6):** `A = H × (n/m)`; жилой дом `2:3 … 8:9`, предельные случаи `1:1` (дворец) и `1:2` (богатая колонно-пилястровая архитектура); для многоэтажных домов берётся `H_max`.
2. **`pfeiler_ohne_umrahmung` (S. 5):** `p = A − w`, проверка `p ≥ w` (`A ≥ 2w`).
3. **`pfeiler_mit_umrahmung` (S. 5):** `w_v = w + 2u`, `p_c = A − (w + 2u)`, проверка `p_c ≥ w_v`.
4. **`eckpfeiler_abstand` (S. 4–5):** `D = k_D × A` (`k_D ∈ [2/3, 5/6]`, по умолчанию `4/5`); `p_corner = D − w/2 − u`. Проверки зависят от типа здания (отдельно стоящий: `p_corner > w`; монументальный: `p_corner > p_intermediate`; городской: допускается `p_intermediate ≥ p_corner`; ризалит на ширину комнаты: `D = ширина_ризалита / 2`).
5. **`fenster_hoehen_grenzen` (S. 6):** `1.5w ≤ h ≤ 2w`.
6. **`fenster_goldener_schnitt` (S. 6–7):** `h = φ·w` (`φ = (1 + √5)/2 ≈ 1.618034`) и практические приближения `3:5, 5:8, 8:13, 13:21, 21:34, 34:55, 55:89, 89:144` (а также `5:9, 4:7`).
7. **`fenster_halbe_diagonale` (S. 7):** `d = √(w² + h²)`, правило `w ≤ d/2`.
8. **`fenster_verdachung_rfk` (S. 7–8):** деление `R:F:K` (`1:1:1, 6:7:8, 4:5:6, 3:4:4, 2:3:3, 3:5:4`).
9. **`ausladung_45_und_konsolen` (S. 8):** вынос по `45°` (`v_proj = K`), с консолями `v_console = (5/6)·K`, равенство отступов `a_front = a_side`.
10. **`pilaster_vorsprung` (S. 11–12):** `v_max = W_p/4`; лёгкий диапазон `W_p/6 … W_p/5`; гладкая лопатка (`Mauerpfeiler`) без базы и капители.
11. **`kranz_gliederung` (S. 10–11):** `h_u : h_l = 1:1` (допустимо `1:2 … 2:1`).
12. **`sockel_gesammthoehe` (S. 16):** оптимально `h_socle = H_total / 6`, типично `1/10 … 1/7`; при `< 1/10` — нарушение.
13. **`hauptgesims_unterordnung` (S. 16):** `h_main < h_socle`; диапазон `[H_total/12, H_total/8]` (≤ 2 эт.) и `[H_total/15, H_total/12]` (> 2 эт.).
14. **`gurtgesims_abmessung` (S. 16):** поясной карниз `h_gurt ∈ [H_floor/12, H_floor/6]` и строго меньше главного карниза и цоколя.
15. **`sockel_dreiteilig` (S. 10):** трёхчастное деление цоколя (`Fuß`, `Rumpf`, `Deckgesims`) и преобладание плиты.
16. **`sockel_abnahme_nach_oben` (S. 10):** убывание высоты руста и выноса профилировки от цоколя к первому этажу.
17. **`sockel_abkroepfung` (S. 10, 12):** предпочтителен сплошной прогон без раскреповок; раскреповки допустимы при подвальных окнах или лопатках.
18. **`sockel_quader_schichten` (S. 17):** высота рядов квадровой кладки `0.30–0.40 м`, предпочтительно нечётное число рядов `n`.
19. **`erdgeschoss_als_sockel` (S. 16, 22):** включение всего 1-го этажа в цоколь при невозможности набрать требуемую высоту.
20. **`varianty_etazhnosti_i_pryamougolnik` (S. 5–6, 14–16, 21–22):** 5 пресетов этажности (`one-story`, `two-story`, `multi-story / three`, `multi-story / four-five`, `multi-story / general`) с автоматическим пересчётом диапазонов карниза/венчающей части, предела `A/H_max`, лежачего/стоячего прямоугольника фасада (с запретом квадрата) и чётности/нечётности осей.
21. **`chetyrekh_pyatietazhnye_skhemy` (S. 22–23):** схема A (`1=цоколь / 2–4=ствол / 5+карниз=венчание`) и схема B (`1+2=нижний ярус / 3–5=ствол / главный карниз`).
22. **`gurtgesims_lenta_pravila` (S. 10–11, 16–17, 22):** межэтажные карнизы (ленты): `H_ленты ∈ [h_нижн/12, h_нижн/6]`, `H_ленты < min(H_цоколя, H_гл.к.)`, 4 класса состава (`венец`, `архитравные полосы + венец`, `шейка и поясок + венец`, `архитрав, фриз и венец`), разбивка венца `1:2…2:1` с перекосом при консолях, согласование с колоннадой, замена рустовкой на базовом профиле, запрет «только подоконника под 2-м этажом» и 3 схемы 3-этажного дома.

### Принятые допущения и эвристики UX (и чего в тексте нет)

В интерфейсе явно помечены как **«допущение/эвристика»**, **«не из источника»** или **«экстраполяция»**:
- **Допуски проверки (`tolerance`):** 3 % по умолчанию для общих отклонений и 5 % для правила половины диагонали окна (`S. 7`), чтобы отличать строгое неравенство `w ≤ d/2` от практического приближения `3:5` (отклонение `≈ 2.9 %`, статус `approx`).
- **Процентные пороги характера карниза (`kranz_charakter_preset`):** доля крупной плиты в верхнем обломе `≥ 75 %` («тяжёлый» эффект) и `≤ 50 %` («лёгкий» эффект с выкружкой/гуськом) — числовая UX-интерпретация качественных указаний на `S. 10–11`.
- **Доли трёхчастного цоколя (`threePartSocle`) и порог плиты (`plateDominant`):** числовые доли по умолчанию `0.25 / 0.55 / 0.20` (`Fuß / Rumpf / Deckgesims`) и коэффициент `1.2×` для преобладания плиты являются эвристической визуализацией качественных указаний на `S. 10`.
- **6 пробелов по этажности (1895):**
  1. Числовые пределы главного карниза и венчающей части для 1-этажного дома не заданы (экстраполяция `≥` норм 2-этажного).
  2. Точный порог «широкого шага осей» для 1–2-этажного дома не указан (`A/H → 1.0`).
  3. Числовые пороги «главного яруса» для 2-го этажа многоэтажного дома описаны качественно (`S. 22`).
  4. Схемы A и B для 4–5-этажного дома (`S. 23`) даны описательно без числовых долей этажей.
  5. Граница «многоэтажный» vs «3-этажный» в тексте не формализована (`S. 16, 22`).
  6. Специальные нормы цоколя для 1-этажного дома отсутствуют (`1/10–1/6`).
- **6 пробелов по межэтажным лентам (1895):**
  1. Числовой вынос (`Ausladung`) ленты — сказано «умеренный» (`S. 16`), без числа.
  2. Точная база отсчёта `h_нижн.эт` (пол-пол или в свету) — принята пол-пол (`экстраполяция`).
  3. Трёхчастность `Fuß : Rumpf : Deckglied` для ленты не описана (`не из источника`).
  4. Числовые пороги «скромного» нижнего этажа при `H_ленты < h/12` отсутствуют.
  5. Числовые соотношения ленты с колоннадой/пилястрами не заданы (`S. 16`).
  6. Высота подоконной плиты, ставшей сплошным карнизом (`S. 17`), задана только качественно.
