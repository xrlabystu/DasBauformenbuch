# Brausewetter 1895 — Das Bauformenbuch, Bd. 1

Цифровое научное издание, корпус текстов и **Интерактивный пропорциональный калькулятор фасада** по книге:

- **Автор:** Brausewetter
- **Издание:** *Das Bauformenbuch*, Bd. 1, 1895
- **Источник факсимиле:** Deutsches Museum ([BV014442283](https://gateway-bayern.de/BV014442283))

---

## Разделы приложения

1. **Читальный зал** — постраничная дипломатическая немецкая транскрипция, русский перевод, синхронизированный вьювер факсимиле и двусторонняя подсветка архитектурной терминологии.
2. **Калькулятор** — параметрический калькулятор пропорций фасада по страницам **S. 1–12**, включающий три подстраницы:
   - *Фасад и калькуляторы* (7 решателей: оси и простенки, окно, угол `D`, обрамление `R:F:K`, пилястр, карниз, сводка + масштабируемый SVG-фасад и 4 геометрические номограммы).
   - *Правила и нормы* (карточки правил из единого JSON-реестра `src/calc/rulesData.json` со ссылками на страницы источника).
   - *Тесты (11 кейсов)* (интерактивная проверка всех контрольных примеров из книги).
3. **Терминология** — двуязычный глоссарий с переходом к месту употребления в тексте.
4. **Корпус JSON / Опись издания** — просмотр и экспорт полного корпуса.

## Архитектура калькулятора и список правил (S. 1–12)

Чистая математическая логика вынесена в `src/calc/rules.ts`, а метаданные правил, типологий и отношений — в `src/calc/rulesData.json`. Все промежуточные расчёты ведутся без округления; отображение форматируется до 3 знаков после запятой (`м`).

1. **`axenweite_zimmerhoehe` (S. 5–6):** `A = H × (n/m)`; жилой дом `2:3 … 8:9`, предельные случаи `1:1` (дворец) и `1:2` (богатая колонно-пилястровая архитектура); для многоэтажных домов берётся `H_max`.
2. **`pfeiler_ohne_umrahmung` (S. 5):** `p = A − w`, проверка `p ≥ w` (`A ≥ 2w`).
3. **`pfeiler_mit_umrahmung` (S. 5):** `w_v = w + 2u`, `p_c = A − (w + 2u)`, проверка `p_c ≥ w_v`.
4. **`eckpfeiler_abstand` (S. 4–5):** `D = k_D × A` (`k_D ∈ [2/3, 5/6]`, по умолчанию `4/5`); `p_corner = D − w/2 − u`. Проверки зависят от типа здания (отдельно стоящий: `p_corner > w`; монументальный: `p_corner > p_intermediate`; городской: допускается `p_intermediate ≥ p_corner`; ризалит на ширину комнаты: `D = ширина_ризалита / 2`).
5. **`fenster_hoehen_grenzen` (S. 6):** `1.5w ≤ h ≤ 2w`.
6. **`fenster_goldener_schnitt` (S. 6–7):** `h = φ·w` (`φ = (1 + √5)/2 ≈ 1.618034`) и практические приближения `3:5, 5:8, 8:13, 13:21, 21:34, 34:55, 55:89, 89:144` (а также `5:9, 4:7`).
7. **`fenster_halbe_diagonale` (S. 7):** `d = √(w² + h²)`, правило `w ≤ d/2`.
8. **`fenster_verdachung_rfk` (S. 7–8):** деление `R:F:K` (`1:1:1, 6:7:8, 4:5:6, 3:4:4, 2:3:3, 3:5:4`).
9. **`ausladung_45_und_konsolen` (S. 8):** вынос по `45°` (`v_proj = K`), с консолями `v_console = (5/6)·K`, равенство отступов `a_front = a_side`.
10. **`pilaster_vorsprung` (S. 11–12):** `v_max = W_p/4`; лёгкий диапазон `W_p/6 … W_p/5`; гладкая лопатка (`Mauerpfeiler`) без базы и капители.
11. **`kranz_gliederung` (S. 10–11):** `h_u : h_l = 1:1` (допустимо `1:2 … 2:1`).

### Принятые допущения и эвристики UX

В интерфейсе явно помечены как **«допущение/эвристика»**:
- **Допуски проверки (`tolerance`):** 3 % по умолчанию для общих отклонений и 5 % для правила половины диагонали окна (`S. 7`), чтобы отличать строгое неравенство `w ≤ d/2` от практического приближения `3:5` (отклонение `≈ 2.9 %`, статус `approx`).
- **Процентные пороги характера карниза (`kranz_charakter_preset`):** доля крупной плиты в верхнем обломе `≥ 75 %` («тяжёлый» эффект) и `≤ 50 %` («лёгкий» эффект с выкружкой/гуськом) — числовая UX-интерпретация качественных указаний на `S. 10–11`.
